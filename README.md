
Common Uses of Functions in Excel

Function

SUM()
Adds numbers together
=SUM(A1:A10)

AVERAGE()
Calculates the mean of values
=AVERAGE(B1:B10)

COUNT()
Counts cells containing numbers
=COUNT(C1:C20)

COUNTA()
Counts non-empty cells
=COUNTA(A1:A20)

MAX()
Finds the highest value
=MAX(D1:D10)

MIN()
Finds the lowest value
=MIN(D1:D10)

IF()
Performs logical tests and returns different results
=IF(E1>=50,"Pass","Fail")

AND()
Checks if multiple conditions are true
=AND(A1>0,B1<100)

OR()
Checks if at least one condition is true
=OR(A1>100,B1>100)

VLOOKUP()
Searches for a value in a table
=VLOOKUP(101,A2:D20,2,FALSE)

XLOOKUP()
Modern lookup function with more flexibility
=XLOOKUP(A2,D:D,E:E)

INDEX() & MATCH()

Advanced lookup and data retrieval
=INDEX(B:B,MATCH(101,A:A,0))

CONCAT() / CONCATENATE()
Joins text from different cells
=CONCAT(A1," ",B1)

LEFT(), RIGHT(), MID()
Extracts portions of text
=LEFT(A1,5)

LEN()
Counts characters in a cell
=LEN(A1)

TODAY()
Returns the current date
=TODAY()

NOW()
Returns the current date and time
=NOW()

ROUND()
Rounds numbers to a specified decimal place
=ROUND(A1,2)

SUMIF()
Adds values based on a condition
=SUMIF(A:A,"East",B:B)

COUNTIF()
Counts cells meeting a condition
=COUNTIF(A:A,"Completed")


Practical Business Applications

Banking: Calculate loan repayments, interest, and account balances.

Sales Analysis: Track revenue, average sales, and top-performing products.

Human Resources: Calculate employee leave balances and attendance statistics.

Inventory Management: Monitor stock levels and reorder points.

Financial Reporting: Create budgets, forecasts, and profit-and-loss analyses.

Data Analysis: Clean, summarize, and visualize large datasets.


Why Use Functions?

Save time by automating calculations.

Reduce manual errors.

Analyze large datasets efficiently.

Generate accurate reports and insights.

Support decision-making with data.

For a Data Analyst role, the most important Excel functions to master are: SUM, SUMIF, COUNTIF, AVERAGE, IF, IFERROR, VLOOKUP/XLOOKUP, INDEX-MATCH, LEFT, RIGHT, MID, LEN, TEXT, ROUND, CONCAT, and Pivot Tables.
